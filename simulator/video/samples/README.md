Poné acá videos reales (o grabados con el celular) de correas transportadoras con el
nombre de la cámara que querés simular, por ejemplo:

- `cv-201-rgb-01.mp4` → cámara RGB de la banda
- `cv-201-th-01.mp4` → cámara térmica de polines

Los `.mp4` están excluidos de git (ver `.gitignore`). Si no hay video, `feed.sh`
genera una señal de prueba.
